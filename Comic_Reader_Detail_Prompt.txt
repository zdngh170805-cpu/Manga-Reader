PROMPT DETAIL — ANDROID COMIC / MANGA READER

TUJUAN UTAMA

Buat sebuah aplikasi Android native bernama “Comic Reader” yang
berfungsi sebagai pembaca manga, manhwa, comic, doujin, artbook, dan
image-based comic secara offline.

Aplikasi harus terasa seperti aplikasi comic reader Android profesional:
cepat, ringan, responsif, fokus pada area gambar, memiliki dark theme
sebagai tampilan utama, serta menyediakan kontrol pembacaan yang
lengkap.

REFERENSI VISUAL

Gunakan referensi screenshot hanya untuk memahami: - struktur layout, -
hierarki toolbar, - bentuk popup, - posisi kontrol, - pola halaman
Settings, - gaya dark UI, - perilaku page reader, - page slider, - page
layout, - page scrolling, - page spacing, - file browser.

JANGAN menyalin logo, watermark, nama situs, artwork manga, karakter,
atau aset berhak cipta dari screenshot. Semua branding dan aset visual
harus dibuat original.

================================================== 1. ARSITEKTUR
APLIKASI ==================================================

Buat aplikasi dengan beberapa area utama:

1.  File Browser / Storage
2.  Directory Browser
3.  History
4.  Bookmark
5.  Comic Reader
6.  Reader Overlay Controls
7.  Settings
8.  Cache Management
9.  Resume Reading
10. Information / About

Gunakan arsitektur aplikasi yang modular agar fitur reader, storage,
settings, cache, dan database tidak saling bergantung secara berlebihan.

Prioritaskan: - performa, - stabilitas, - penggunaan RAM rendah, -
scrolling halus, - loading gambar cepat, - state persistence, - dukungan
file besar, - dukungan layar portrait dan landscape.

================================================== 2. HALAMAN UTAMA /
FILE BROWSER ==================================================

Buat halaman file browser dengan dark theme.

Bagian atas mempunyai tab atau navigation:

-   Storage
-   Directory
-   History
-   Bookmark

Storage menampilkan: - Recent - Internal Storage / Device - SD Card -
folder - file comic - file image - archive comic

Contoh path: /storage/emulated/0 /storage/XXXX-XXXX

Jika SD Card tersedia, tampilkan sebagai lokasi terpisah.

Recent: - tampilkan file yang terakhir dibuka, - tampilkan nama file, -
folder path, - thumbnail jika tersedia, - waktu terakhir dibuka jika
memungkinkan.

Directory: - navigasi folder, - tombol kembali, - breadcrumb/path, -
daftar folder, - daftar file, - sorting.

History: - daftar comic yang pernah dibuka, - posisi halaman terakhir, -
thumbnail, - nama file, - tombol resume.

Bookmark: - daftar halaman yang ditandai, - comic asal, - nomor
halaman, - thumbnail, - tombol membuka langsung halaman tersebut.

Gunakan list view yang sederhana dan cepat.

================================================== 3. FLOATING ACTION
BUTTON ==================================================

Tambahkan floating button di bagian kanan bawah file browser.

Fungsinya dapat berupa: - membuka file terakhir, - quick resume, -
membuka file picker.

Sediakan opsi untuk mengaktifkan atau menonaktifkannya melalui Settings.

================================================== 4. FORMAT FILE
==================================================

Minimal dukung:

IMAGE: - JPG - JPEG - PNG - WEBP - GIF jika memungkinkan

COMIC ARCHIVE: - ZIP - CBZ - RAR jika library yang digunakan
memungkinkan - format archive lain hanya jika aman dan stabil.

Jangan memuat seluruh archive ke RAM.

Gunakan streaming atau random access bila memungkinkan.

Urutkan halaman berdasarkan nama file secara natural:

1.webp 2.webp 3.webp … 10.webp

Jangan mengurutkan secara alfabet biasa sehingga 10.webp muncul sebelum
2.webp.

disembunyikan, - overlay UI tidak mengganggu pembacaan.

================================================== 7. PAGE LAYOUT
==================================================

Buat popup bernama:

“Page layout”

Pilihan:

-   Off
-   Single page
-   Dual pages
-   Auto

OFF: Reader menggunakan mode dasar yang dipilih.

SINGLE PAGE: Tampilkan satu halaman dalam satu waktu.

DUAL PAGES: Tampilkan dua halaman secara berdampingan.

AUTO: Aplikasi menentukan layout berdasarkan: - orientasi perangkat, -
ukuran halaman, - aspect ratio, - ukuran viewport.

Perilaku Auto: - portrait: default single page, - landscape/tablet:
default dual page jika ruang mencukupi.

Sediakan opsi untuk menyesuaikan urutan halaman dalam mode dual page.

================================================== 8. RTL / LTR
==================================================

Reader harus mendukung:

LTR: Left To Right

RTL: Right To Left

Untuk manga Jepang gunakan RTL.

Untuk comic Barat gunakan LTR.

Mode reading direction memengaruhi: - swipe, - tombol next/previous, -
urutan dual pages, - page scrolling, - page preloading, - progress
navigation.

Jangan hanya membalik animasi; seluruh logika navigasi harus mengikuti
direction.

================================================== 9. PAGE SCROLLING
==================================================

Buat popup:

“Page scrolling”

Pilihan visual:

-   Right
-   Left
-   Right + Vertical
-   Left + Vertical

Right: Halaman bergerak ke kanan.

Left: Halaman bergerak ke kiri.

Right + Vertical: Mendukung pembacaan horizontal dengan transisi
vertikal.

Left + Vertical: Versi berlawanan untuk RTL.

Reader harus mendukung: - swipe, - fling, - tap navigation, - drag
ketika zoom, - vertical continuous scrolling jika mode dipilih.

================================================== 10. PAGE SPACING
==================================================

Buat dialog:

“Page spacing”

Terdapat: - checkbox enable, - slider, - nilai percentage.

Contoh: -30.0%

Slider harus dapat mengatur jarak antar halaman.

Nilai negatif: - halaman dapat lebih rapat, - cocok untuk image split
atau scan tertentu.

Nilai positif: - memberikan gap antar halaman.

Perubahan harus langsung terlihat.

================================================== 11. PAGE DIVIDING
LINE ==================================================

Tambahkan pengaturan:

Page dividing line - dual pages

Jika aktif: - tampilkan garis pemisah di antara dua halaman.

Tambahkan:

Page dividing line - scroll pages

Jika aktif: - tampilkan garis pemisah antar halaman ketika scrolling.

Garis harus halus dan tidak mengganggu manga.

================================================== 12. FULL SCREEN
==================================================

Pengaturan:

Full screen

Deskripsi: “Hide status bar, navigation bar”

Ketika aktif: - sembunyikan status bar, - sembunyikan navigation bar, -
reader menggunakan area layar maksimal.

Pastikan aplikasi menangani edge-to-edge Android dengan benar.

Jangan sampai konten tertutup oleh: - notch, - punch-hole, - navigation
gesture area.

================================================== 13. PUNCH-HOLE
DISPLAY ==================================================

Sediakan:

Punch hole display - portrait

Punch hole display - landscape

Tujuan: memperluas area image rendering agar layar di sekitar kamera
punch-hole dapat dimanfaatkan.

Reader harus memperhatikan: - display cutout, - safe area, -
orientation, - status bar, - edge-to-edge.

Jangan memaksa gambar berada di bawah kamera jika hasilnya mengganggu
pembacaan.

================================================== 14. ZOOM DAN PAN
==================================================

Implementasikan:

-   pinch-to-zoom,
-   double tap zoom,
-   zoom in,
-   zoom out,
-   pan,
-   drag.

Saat zoom aktif: - jangan langsung mengganti halaman ketika gesture
sebenarnya dimaksudkan untuk pan.

Double tap: - pertama memperbesar, - kedua mengembalikan ke
fit-to-screen.

Zoom harus memiliki batas maksimum agar tidak menyebabkan penggunaan
memory berlebihan.

================================================== 15. IMAGE SCALING
==================================================

Sediakan beberapa strategi rendering:

-   Fit Width
-   Fit Height
-   Fit Screen
-   Original Size

Default: Fit Screen atau Fit Width tergantung jenis halaman.

Untuk manga panjang: Fit Width dapat digunakan dalam vertical scrolling.

Untuk halaman standar: Fit Screen.

================================================== 16. IMAGE ADJUSTMENT
==================================================

Tambahkan image adjustment sederhana:

-   brightness,
-   contrast,
-   grayscale jika memungkinkan,
-   sharpen opsional,
-   invert opsional.

Jangan melakukan pemrosesan permanen terhadap file asli.

Filter hanya diterapkan pada rendering.

================================================== 17. PAGE NAVIGATION
==================================================

Bagian bawah reader menampilkan:

226-227 / 641

Contoh: - Single page: 226 / 641 - Dual page: 226-227 / 641

Tambahkan progress slider.

Slider harus: - dapat disentuh, - dapat digeser, - memperbarui halaman
secara cepat, - tidak memuat seluruh halaman saat slider digeser.

Gunakan thumbnail preview atau page number preview jika memungkinkan.

================================================== 18. PAGE PRELOADING
==================================================

Untuk performa:

Saat pengguna berada di halaman N: - preload N+1, - preload N-1, -
jangan preload terlalu banyak.

Pada dual page: - preload pasangan halaman berikutnya.

Gunakan LRU cache.

Jika RAM rendah: - kurangi ukuran cache otomatis.

================================================== 19. MEMORY MANAGEMENT
==================================================

Comic dapat memiliki gambar beresolusi sangat tinggi.

Jangan decode gambar dalam ukuran original jika tidak diperlukan.

Gunakan: - sampled decoding, - bitmap reuse, - downsampling, - memory
cache, - disk cache, - lifecycle-aware loading.

Ketika berpindah halaman: - release bitmap yang tidak diperlukan.

Pastikan tidak terjadi: - OutOfMemoryError, - memory leak, - bitmap
accumulation.

dekoratif, - checkbox yang tidak menyimpan state, - page indicator
palsu, - reader yang hanya menampilkan satu image statis.

Prototype boleh menggunakan sample data, tetapi arsitektur harus siap
untuk file comic nyata.

Pastikan state bertahan setelah: - rotation, - background/foreground, -
activity recreation, - aplikasi ditutup dan dibuka kembali.

================================================== 59. FINAL DESIGN
DIRECTION ==================================================

Bayangkan produk akhir sebagai:

“Professional Android offline manga reader with a clean dark Material
interface, high-performance image renderer, advanced page layout
controls, RTL/LTR support, dual-page reading, zoom/pan, persistent
reading progress, SD Card support, caching, bookmarks, history, and
highly configurable reader settings.”

Tampilan harus sederhana ketika membaca, tetapi sangat lengkap ketika
pengguna membuka Settings.

Reader harus mengutamakan gambar comic. Settings harus mengutamakan
keteraturan. File browser harus mengutamakan kecepatan. Semua UI harus
responsif dan nyaman digunakan dengan satu tangan.

Gunakan desain original dan jangan menyalin branding, watermark, logo,
atau artwork dari screenshot referensi.
